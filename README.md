# IC-705 — цифровые моды в браузере

Декодирование DMR с промежуточной частоты Icom IC-705 целиком в браузере.
Демодуляция на JavaScript, декодер [dsd-fme](https://github.com/lwvmobile/dsd-fme)
собран в WebAssembly, управление радио по CI-V через Web Serial.
На компьютер не устанавливается ничего.

**[Открыть →](https://sinty.github.io/Icom705WebDigital/)**

```
USB-кодек IC-705 ──► AudioWorklet ──► Worker ──────────────► AudioWorklet
   ПЧ ~12 кГц         блоки по 2048    демодулятор (JS)       8 кГц → 48 кГц,
                                       → кольцевой буфер      TS1/TS2 по каналам
                                       → dsd-fme (WASM)
                                       → голос и лог
CAT-порт ──► Web Serial ──► CI-V: частота, S-метр, диапазоны, панорама
```

## Что нужно

- **Chrome или Edge на настольной системе.** Web Serial и сырой стереовход
  Web Audio есть только там; Safari, Firefox и мобильные не подойдут.
- IC-705 по USB. Настройки радио:
  `Connectors → USB AF/IF Output → AF/IF = IF`, уровень `IF Output Level` 50–70 %,
  `CI-V Address = A4h`, `CI-V USB Baud Rate = Auto`. Зарядку по USB лучше выключить.

Радио не обязательно, чтобы посмотреть, работает ли всё: на странице есть
**самопроверка** — она прогоняет эталонную запись через тот же тракт и должна
дать голос и лог декодера.

## Главная находка

**ПЧ-выход IC-705 не квадратурный.** Это один вещественный сигнал на ~12 кГц,
продублированный в оба канала со сдвигом ровно в один отсчёт: на 12 кГц это почти
90°, отсюда и видимость I/Q. Измерено на двух эталонных записях —
`corr(R[n], L[n-1]) = +1.000000`.

Практическое следствие: **моно декодируется почти так же** — 101 ошибка звука
против 85 на «стерео». Второй канал даёт около 16 %, а не разницу в разы, и
проект от него не зависит.

Это и десяток других вещей, выясненных измерением, собраны в
**[NOTES.md](NOTES.md)** — включая то, что противоречит документации и соседнему
проекту, и почему вокодер от прошивки MD380 остался за бортом.

## Проверки

Всё проверяется на эталонных записях, снятых с рабочей сборки на Raspberry Pi,
а не на глаз:

```bash
node test/scope_frames.mjs        # сборка развёрток панорамы, 12 проверок
node test/dsp_check.mjs           # демодулятор против GNU Radio
node test/chain_check.mjs         # вся цепочка блоками, как в браузере
node native/test/rb_decode.mjs    # шов ввода в WASM-декодер
```

Результаты, которые эти тесты закрепляют:

| проверка | результат |
|---|---|
| демодулятор против флоуграфа GNU Radio | корреляция 0.999997 |
| голос после декодера против нативной сборки aarch64 | побитово, `sync=1299`, `crc-err=51` |
| обработка блоками против сплошной | 100.00 % совпадения |
| скорость декодирования | около x5 реального времени |

## Локальный запуск

```bash
python tools/serve.py 8000
```

и открыть `http://localhost:8000/`. Обычный `python -m http.server` **не
подойдёт**: он отдаёт `.mjs` как `text/plain`, браузер отказывается исполнять
такой модуль, и воркер не стартует молча.

Сборка WASM-декодера (нужен [emsdk](https://emscripten.org/), ninja, cmake):

```bash
source native/emenv.sh
emcmake cmake -G Ninja -B native/build -S native && ninja -C native/build
```

Исходники dsd-fme, mbelib и libsndfile не хранятся в репозитории — как их
забрать и на каких коммитах всё проверено, видно в
[.github/workflows/pages.yml](.github/workflows/pages.yml).

## Что сделано и что нет

Работает: DMR, панорама в стиле родного экрана, частота, режим, S-метр,
кнопки диапазонов, переключение AF/IF, выбор слота TS1/TS2, запоминание
звуковой карты и CAT-порта между сессиями.

Не сделано: D-STAR, YSF и NXDN (эталонные записи для них уже лежат в `ref/`),
журнал услышанных операторов, передача. Вокодер — mbelib; вариант с прошивкой
MD380 разобран в NOTES и отклонён.

## Лицензия и происхождение

Код этого репозитория — [ISC](LICENSE). Но собранный `dsd-fme-rb.wasm` —
**комбинированное произведение под GPL**: часть файлов dsd-fme распространяется
под GPL-2.0-only и GPL-3.0, и они линкуются в результат. Подробный разбор — в
[LICENSE](LICENSE).

Декодер — [dsd-fme](https://github.com/lwvmobile/dsd-fme), вокодер —
[mbelib](https://github.com/lwvmobile/mbelib), чтение файлов —
[libsndfile](https://github.com/libsndfile/libsndfile). Формат кадров панорамы
сверен с [wfview](https://wfview.org/). Параметры радио и методика отладки
взяты из предшествующего проекта на Raspberry Pi.
