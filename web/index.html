IC-705 — декодер цифровых мод в браузере

DMR с ПЧ-выхода по USB. Ничего не устанавливается: демодуляция на JS, декодер — dsd-fme в WebAssembly.

На радио: Connectors → USB AF/IF Output → AF/IF = IF, уровень IF Output Level 50–70 %. Нужен Chrome или Edge — Web Audio с сырым стереовходом есть только там.
