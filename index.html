IC-705 — цифровые моды в браузере

DMR с ПЧ-выхода Icom IC-705. Демодуляция на JavaScript, декодер dsd-fme собран в WebAssembly, управление радио по CI-V через Web Serial. Устанавливать на компьютер не нужно ничего.

проверяю поддержку браузера…
Открыть декодер → Захват ПЧ, декодирование DMR, панорама и управление радио. Есть самопроверка на эталонной записи — работает и без радио. Панорама: предпросмотр → Отрисовка панорамы на синтетическом сигнале. Радио не требуется.
Настройки радио. Connectors → USB AF/IF Output → AF/IF = IF, уровень IF Output Level 50–70 %. Для управления по CI-V: CI-V Address = A4h, CI-V USB Baud Rate = Auto. Зарядку по USB лучше выключить.

Что нужно

  • Chrome или Edge на настольной системе. Web Serial и сырой стереовход Web Audio есть только там — Safari, Firefox и мобильные не подойдут.
  • IC-705, подключённый по USB. Второй канал звука необязателен: ПЧ-выход отдаёт один сигнал, продублированный со сдвигом в отсчёт, и моно декодируется почти так же.
Исходники, история находок и методика проверок — на GitHub. Декодер — dsd-fme, вокодер — mbelib.
